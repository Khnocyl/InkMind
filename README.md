## 核心特性

InkMind 专为长篇小说（百万字级别连载）量身打造，区别于单次聊天的通用 AI，构建了工业级的长篇创作基础设施：

### 1. 自研六阶段写章管线（多 Agent 严格协同）
- **细纲分镜规划（Planner）**：自动将粗大纲拆解为多幕节拍分镜，精确设计情节悬念、冲突递进与段落字数预期。
- **流式正文执笔（Writer）**：严格依附世界观设定与前文伏笔进行长文写作，支持实时流式打字生成。
- **确定性结构校验（Validator）**：集成 SchemaGate 智能闸门，自动回显校验错误并智能重试，杜绝 JSON 截断或格式乱码。
- **AI 味深度清洗（Taste Cleaner）**：深度扫描并过滤“说实话”、“心中暗道”等 AI 成语滥用、感叹号与空洞套话。
- **定向局部修复（Reviser）**：审计出硬伤时，针对问题段落局部靶向重写，绝不暴力推翻整章正常情节。
- **记忆与账本回写（Settler）**：成章后自动沉淀单章摘要、更新伏笔债务、记录人物状态变迁。

### 2. 百万字长篇记忆中枢（彻底杜绝吃设定）
- **动态事实账本（Fact Ledger）**：长线追踪角色生死、境界等级、伤病状态、关键宝物道具归属与势力从属。
- **伏笔与债务系统**：正文中埋下的暗线自动建档追踪，跨越数十万字智能提醒未回收伏笔，告别“挖坑不填”。
- **分层记忆压缩体系**：单章纲要（Recap）+ 分卷跨度长篇摘要（Digest）分级提炼，海量上下文永不溢出。
- **写前动态相关度检索**：创作新章节前，自动提取与本章人物/情节最相关的前文记忆切片注入 Prompt，精准防断层。

### 3. 全维逻辑一致性防线
- **六维硬伤审查（Hard Review）**：实时严密审核角色状态异常、战力崩塌、时间线倒流、吃书冲突、道具凭空出现与叙事人称错乱。
- **跨章连续性抽检**：智能随机回溯前文章节对比，排查长篇连载中潜在的情节逻辑暗病与设定漂移。
- **本地机检与禁忌词库**：内置敏感词排查、高频词重复度分析与句式单调性诊断。

### 4. 文风克隆与定制化引擎
- **名家文风深度萃取**：导入优秀小说样章，自动提取叙事节奏、词汇偏好、修辞习惯与描写风格。
- **多文风档案随心换**：支持保存多套文风（古典仙侠、硬核科幻、现代悬疑、热血脑洞等），创作时一键切换。
- **负向写作纪律约束**：可自定义禁用词、禁用情节套路与写作风格戒律，强力约束大模型创作边界。

### 5. 模块化世界观与世界书体系
- **立体化设定档案**：角色库（性格/背景/口癖/境界技能）、地理大地图、力量等级划分、宗门门阀、神兵灵药。
- **多级大纲架构**：总纲主线 → 分卷脉络 → 章节细纲 → 幕次节拍，层层递进掌控长篇走向。
- **设定变更全生命周期**：角色升级、法宝转让、势力灭亡状态联动全局自动同步。

### 6. 本地优先（Local-first）与企业级安全
- **100% 数据归作者所有**：所有小说大纲、正文、设定与向量索引均存储于创作者本地 IndexedDB，绝不擅自上传云端。
- **API Key 机器唯一加密**：密钥采用本地硬件指纹与 AES-256-GCM 强加密存储，前端与日志永不暴露明文。
- **防丢稿工程兜底**：流式写章毫秒级本地持久化、多版本 gzip 历史快照还原、跨标签页防并发冲突锁与磁盘写入合并。

### 7. 大模型调度与成本控制
- **自由自带 Key（BYOK）**：原生支持标准 OpenAI 协议（DeepSeek、OpenAI、Kimi、智谱 GLM、通义千问等主流大模型及代理）。
- **按创作角色灵活路由**：支持将便宜模型分配给摘要整理与机检，高端模型负责主线大纲推理与高光正文执笔，成本骤降 70%。
- **用量与预算实时看板**：每章 Token 消耗与费用一目了然，提供月度预算硬阻断与 LLM 故障自动降级机制。
- **一键 Doctor 连通性诊断**：一秒检测当前 API 端点连通性、加密凭据有效性、流式吞吐速度与 JSON 遵从能力。

### 8. 创作者专属工作台体验
- **沉浸式双模式排版**：支持经典浅色与深色（暗色）沉浸夜间模式，专为深夜执笔进行高对比度护眼优化。
- **多格式导出与备份**：一键导出作品为纯文本 TXT、Markdown 或分卷分章目录压缩包。
- **内置在线版本检测**：设置面板一键检查 GitHub Releases 官方最新更新，无缝体验新特性。

## 快速开始

需要 Node.js 20+。

```bash
npm install

# 开发模式（前后端热重载）
npm run dev
# 浏览器打开 Vite 端口（默认 http://localhost:5173）

# 或：构建 + 单进程运行（Express 直接托管 dist，一个端口跑完整应用）
npm start
# 打开 http://localhost:3001

# 或：打成单文件可执行（免装 Node，给不懂开发的作者用）
npm run build:exe
# 产物在 release/：inkmind.exe + dist/ + 使用说明.txt，双击即用
```

首次使用：进入「风格与引擎」页签，配置 LLM 的 Base URL / API Key / 模型名（支持 DeepSeek、Kimi、GLM、SiliconFlow 等 OpenAI 兼容服务，可存多套配置档）。API Key 由本地服务端加密存储，不会进入前端代码或 git。

## 隐私须知

- 作品数据（章节、设定、记忆）全部存在**本地浏览器 IndexedDB**，不上传任何服务器。
- 但**写作过程中正文会发送给你配置的 LLM 服务端点**。若使用第三方中转站（非模型官方 API），等同于信任该中转站，配置页会对非官方端点显示警告。
- 可选的向量检索（Embedding）同样只调用你配置的服务；未配置时自动使用本地 TF-IDF 检索，写作流程不中断。

## 常用命令

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发模式（server watch + Vite） |
| `npm start` | 构建并用单进程跑生产形态（http://localhost:3001） |

| `npm test` | vitest 单测 |
| `npm run lint` | oxlint |

## 目录结构

- `src/engine/` — 写章管线与 agents（Planner/Writer/Validator/Auditor/Reviser/Settler）
- `src/services/` — 领域服务（记忆、事实账本、检索、成本、快照、迁移等）
- `src/hooks/` — App 级编排（管线、章节动作、Auto-Pilot、持久化）
- `src/components/` — UI（工作台 / 世界书 / 大纲 / 风格与引擎）
- `server/` — Express：LLM 代理（多配置档 + Token 鉴权）、Embedding、Doctor 诊断
- `tests/` — vitest 单测（服务层纯函数）
- `RISKS.md` — 风险清单与修复跟踪

详细引擎说明见 `ENGINE.md`。
