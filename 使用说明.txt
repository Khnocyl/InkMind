InkMind — AI 长篇小说创作工作台（源码运行版）

【运行要求】
- Node.js 18 或更高版本（https://nodejs.org 下载 LTS 版）
- 首次使用需在「设置」页填写 LLM 的 Base URL / API Key / 模型名

【启动方法】
方式一（Windows）：双击「启动.bat」
  - 首次运行会自动安装依赖（npm install）并构建前端，约 2-3 分钟
  - 完成后浏览器访问 http://localhost:3001
方式二（命令行）：
  npm install        （首次）
  npm run start      （构建 + 启动，浏览器开 http://localhost:3001）
开发模式（前端热更新）：npm run dev（前端 5173 / 后端 3001）

【数据与隐私】
- 你的 API Key 加密保存于本目录 .novel-data/，且与本机绑定——
  拷到别的电脑无法解密（需重新填写）
- 作品数据保存在浏览器（IndexedDB）+ 本目录 .novel-data/backups/ 自动备份
- 卸载/搬家：直接删除或拷走整个文件夹即可
- 不要把 .novel-data/ 分享给他人（内含 API Key 密文与你的作品数据）
- 本包源码不含任何密钥与作品数据

【常用入口】
- 顶部 >_ 按钮：查看每次发给 AI 的 Prompt 与原始响应（排查用）
- 设置页 → 文风仿写：内置多种风格与预设，
  文风会参与书名、世界观、大纲、拆章、分镜到正文的全流程
- 写作页右栏：写作仪表盘 / 待修清单 / 一键修全部
